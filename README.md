# Датский квартал — партнёрский сайт для риелторов

Рабочий кабинет агента: 3D-генплан с кликабельными домами, живой реестр 46 квартир,
фото почти по каждому лоту, планировки, портреты покупателя, условия и расчёты.
Без регистрации и паролей, мобильная версия в приоритете.

## Публикация

Сайт живёт на GitHub Pages: **https://hrustalniconcept.github.io/datsky-agents/**

Деплой автоматический. Любой пуш в `main` запускает workflow
`.github/workflows/pages.yml`, который выкладывает содержимое репозитория как есть.
Обновили `data/registry.json` — сделали коммит и пуш, через пару минут сайт свежий.

```bash
git add -A && git commit -m "Реестр от 16.09" && git push
```

## Ипотека и закон «О рекламе»

На публичных страницах **нет процентных ставок, размеров платежа и названий банков**.
Часть 3.2 статьи 28 закона «О рекламе» требует: если реклама содержит хотя бы одно
условие, влияющее на стоимость кредита, она обязана содержать все такие условия.
Выполнить это на странице сайта нереально, поэтому цифры вынесены в персональную
переписку — расчёт под конкретного клиента присылается по запросу через форму.

Что нельзя возвращать на открытые страницы:

- процентные ставки в любом виде, включая «от 6%»
- размер ежемесячного платежа
- названия банков и ипотечных продуктов
- матрицу субсидирования с колонкой «нам стоит»

Методику — точку равенства, порядок разговора, правило «скидка и субсидия не
суммируются» — публиковать можно: это не оффер.

## Как запустить

Сайт читает данные из `data/*.json`, поэтому открывать его нужно по http,
а не двойным кликом по файлу.

```bash
python3 -m http.server 8811
```

Дальше `http://localhost:8811`.

## Журнал обновлений

Раздел «Материалы» открывается блоком «Что изменилось за последнее время».
Чтобы добавить запись, допишите объект в начало `data/updates.json → zhurnal`:

```json
{ "d": "2026-09-15", "r": "Квартиры и цены", "t": "Заголовок",
  "d2": "Что именно поменялось", "href": "#/flats", "new": true }
```

Флаг `new` рисует красную метку «новое» — снимайте его через пару недель.
Три свежие записи автоматически показываются на главной.

Таблица «что и как часто обновляется» лежит там же, в `reglament.chastota`.

## Подписка и закон

Форма подписки собирает **два отдельных согласия**:

1. на обработку персональных данных (152-ФЗ, ст. 9);
2. на получение рекламных сообщений — часть 1 статьи 18 закона «О рекламе»
   требует предварительного согласия абонента, поэтому галочка отдельная
   и не проставлена заранее.

Оба факта с датой и временем попадают в текст заявки — хранить их обязан
рекламораспространитель. Без второй галочки форма не отправляется.

Перед запуском рассылки формулировки согласий и страницы `/policy` и `/agree`
должен утвердить юрист. В форме собираются только имя, агентство и один контакт —
минимум, необходимый для отправки писем.

## Что осталось подключить

0. **Первые этажи (ВСС).** Шесть квартир вернулись в продажу: первые этажи
   с участком 60 м², площади 59,9–89,9 м². Комплекта фото и чертежей по ним нет,
   товарный тип проставлен по ближайшему метражу — в карточке стоит предупреждение.
   Нужна съёмка и подтверждение планировок.
1. **Приём заявок.** `data/site.json → formy.webhook` = `null`. Форма собирает
   заявку и отдаёт кнопками «скопировать / почта / Telegram». Подставьте endpoint —
   пойдёт POST.
2. **Счётчик аналитики.** Отдельный номер Метрики для партнёрского поддомена не заведён.
3. **3D-планировки.** Ни одного 3D по девяти типам. Чертежи и фото есть.
4. **Видео по типам B2, C и F.** В канале обзоров этих форматов нет.
5. **Страницы `/policy` и `/agree`.** Без них формы запускать нельзя (152-ФЗ).
