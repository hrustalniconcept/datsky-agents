# Приёмник заявок

Заявки с сайта уходят в группу Telegram. Токен бота хранится в секретах
Cloudflare Worker, а не в коде сайта — сайт публичный, и в его исходниках токен
увидел бы любой желающий.

```
форма на сайте  →  POST на Worker  →  Telegram Bot API  →  группа «Заявки»
```

## Шаг 1. Бот и группа (делается в Telegram, 3 минуты)

1. Напишите @BotFather → `/newbot` → задайте имя и username.
   BotFather пришлёт **токен** вида `8123456789:AAF...` — это пароль, никому не пересылайте.
2. Создайте группу, например «Датский · заявки с сайта».
3. Добавьте туда бота и тех, кто должен видеть заявки — РОПа, менеджеров.
4. Узнайте id группы: добавьте в неё бота @getmyid_bot либо откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после любого сообщения в группе
   и возьмите `chat.id`. У групп он отрицательный, например `-1001234567890`.

## Шаг 2. Worker (делается в Cloudflare, 5 минут, бесплатно)

1. Заведите аккаунт на dash.cloudflare.com, раздел **Workers & Pages** → **Create Worker**.
2. Назовите `datsky-zayavki`, нажмите Deploy, затем **Edit code**.
3. Вставьте содержимое `worker/index.js` из этого репозитория, сохраните.
4. **Settings → Variables and Secrets** добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `TG_TOKEN` | Secret | токен от BotFather |
   | `TG_CHAT_ID` | Secret | id группы, с минусом |
   | `ALLOWED_ORIGIN` | Text | `https://hrustalniconcept.github.io` |

5. Скопируйте адрес вида `https://datsky-zayavki.<ваш>.workers.dev`.

## Шаг 3. Подключить сайт

В `data/site.json` укажите адрес и запушьте:

```json
"formy": { "webhook": "https://datsky-zayavki.xxx.workers.dev" }
```

Через пару минут после пуша формы начнут отправлять заявки в группу.
Пока поле `null`, форма собирает заявку и отдаёт её кнопками
«скопировать / почта / телеграм» — как сейчас.

## Проверка

```bash
curl -X POST https://datsky-zayavki.xxx.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"text":"Тестовая заявка"}'
```

В группе должно появиться сообщение.

## Защита от спама

В форме есть скрытое поле-ловушка: человек его не видит, робот заполняет.
Такие заявки Worker молча отбрасывает. Если спам всё же пойдёт, добавьте в Worker
ограничение по частоте через Cloudflare KV или включите Turnstile.

## Что важно помнить

- Токен бота — учётные данные. Не кладите его в репозиторий и не присылайте в переписке.
- Заявки содержат персональные данные клиентов. Доступ в группу — только тем,
  кто их обрабатывает; состав участников стоит пересматривать при смене менеджеров.
- Хранение переписки в Telegram не заменяет CRM: закрепление фиксируется в CRM,
  группа нужна для скорости реакции.
